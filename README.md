# Schematica-Neo

**Schematica-Neo** 是一个面向 **Minecraft 1.7.10** 的 Schematica 扩展与现代化改进模组，在保留经典投影加载、显示、材料统计和打印功能的基础上，增加了投影编辑、结构文件转换、更灵活的可见范围控制，以及针对 **魔法金属（ManaMetalMod）** 的兼容支持。

本项目主要用于改善大型建筑投影的查看、修改、转换与辅助建造体验。

## 主要功能

### 投影加载与控制

- 加载和显示 `.schematic` 投影文件。
- 移动、旋转、翻转和卸载投影。
- 保存投影坐标与变换状态。
- 支持多种投影可见模式：
  - 全部可见
  - 分层可见
  - 选区可见
  - 单方块可见
- 单方块可见模式可从背包中选择目标方块和元数据。
- 支持隐藏或重新显示当前投影。

### 投影编辑

功能界面提供统一的投影编辑系统。开启编辑总开关后，可以使用以下模式：

- **选区**
  - 在世界或已加载投影中创建选区。
  - 使用 `Ctrl + 鼠标滚轮` 调整选区大小。
  - 使用 `Alt + 鼠标滚轮` 移动选区。
  - 使用 `Alt + 鼠标中键` 将选区中心重置到玩家附近。
  - 可开启双键选点，使用鼠标左键和右键设置选区的两个对角点。

- **复制**
  - 将选区中的世界方块或投影方块复制到临时缓存。

- **剪切**
  - 将投影选区复制到缓存，并从当前投影中删除对应方块。

- **粘贴**
  - 在正式合并前显示缓存方块和范围预览。
  - 可沿玩家视线移动粘贴位置。
  - 合并时保留原投影重叠位置中的已有方块。
  - 粘贴范围超出原投影边界时自动扩展投影。

- **替换方块**
  - 从玩家背包中选择替换目标。
  - 支持修改目标元数据。
  - 可按单个、选区或全部范围替换同类方块。

- **轮换方块元数据**
  - 支持单个、选区或全部范围。
  - 可增加或减少目标方块的元数据。

- **移动投影**
  - 使用 `Alt + 鼠标滚轮` 沿玩家主要视线方向移动投影。
  - 使用 `Alt + 鼠标中键` 将投影重置到玩家附近。

### 保存功能

保存功能分为两种：

- **保存选区**
  - 将当前选区保存为新的投影文件。
  - 可选择从实际世界或当前投影中读取方块。

- **保存投影**
  - 保存经过复制、剪切、粘贴、替换或元数据调整后的完整投影。

## 结构文件导入

Schematica-Neo 可以将部分高版本结构文件转换为 Minecraft 1.7.10 可使用的 `.schematic` 文件。

目前支持：

- 原版 `.nbt` 结构文件
- `.litematic` 文件

该转换功能主要针对 **魔法金属（ManaMetalMod）** 环境设计，会根据项目内置的方块映射表，将 Minecraft 1.13 及以上版本的方块状态转换为 Minecraft 1.7.10 或魔法金属中的对应方块。

如果某个方块没有可用映射：

- 使用带编号的标记方块代替。
- 生成标记方块序号与缺失方块之间的对照列表。
- 可将对照保存为本地文本文件。
- 单人游戏中可生成对照书并放入玩家背包。

由于标记方块由 Schematica-Neo 提供，服务器未安装本模组时可能无法正确显示，因此建议优先在单人游戏或已安装本模组的服务器中使用结构转换功能。

## 材料列表

- 统计投影中的方块和玩家背包中的可用材料。
- 区分已放置数量、总数量和仍需材料。
- 支持按名称或数量排序。
- 可切换纯数量与“组:个”显示格式。
- 可将材料列表导出为本地文本文件。
- 导出内容包含总数量、堆叠数量和存储容量估算。

## 辅助打印

- 自动从玩家物品栏中选择所需材料。
- 支持按层或按距离优先放置。
- 支持不同打印速度档位。
- 默认速度为“快”。
- 单人游戏最高可使用实验性高速档位。
- 多人服务器最高限制为 `3x`，避免过高的放置频率影响服务器平衡。
- 对上下半砖、楼梯、活塞、火把、门、漏斗等具有特殊放置规则的方块进行方向与点击位置处理。

## 魔法金属兼容

项目包含部分针对 **ManaMetalMod** 的专用兼容：

- 高版本方块到魔法金属方块的转换映射。
- 魔法金属特殊方块的预览异常隔离。
- 魔法金属半砖的特殊元数据规则：
  - `0`：下半砖
  - `1`：上半砖
  - `2`：上下合并的整砖
- 扩展元数据读取、编辑和保存支持。

这些兼容逻辑仅针对 `manametalmod` 注册域生效，不会改变原版半砖的元数据规则。

## 操作提示

- `Shift + 鼠标滚轮`：切换编辑模式。
- `Ctrl + 鼠标滚轮`：在选区模式中调整选区大小。
- `Alt + 鼠标滚轮`：根据当前模式移动选区、粘贴预览或投影。
- `Alt + 鼠标中键`：重置选区中心或投影位置。
- `Enter`：在复制、剪切或粘贴模式中执行对应操作。
- 编辑功能可能屏蔽部分原版鼠标操作，不使用时建议关闭编辑总开关。

具体按键可以在 Minecraft 的按键设置界面中调整。

## 适用环境

- Minecraft `1.7.10`
- Minecraft Forge `10.13.4.1614`
- Java 8
- 依赖 LunatriusCore
- 支持单人游戏和多人服务器
- 对 ManaMetalMod 提供额外兼容

## 当前状态

本项目仍在持续开发和测试中。投影编辑、特殊方块渲染、复杂 Tile Entity、模组自定义放置逻辑以及大型投影性能等功能，可能仍存在未覆盖的边界情况。

如果遇到问题，请在 Issue 中提供：

- Minecraft、Forge 和 Schematica-Neo 版本
- 已安装的相关模组版本
- 可复现步骤
- 崩溃报告或 `latest.log`
- 发生问题的方块注册名和元数据
- 如有可能，附上用于复现的投影文件
